## End to End Machine Learning Project

🧠 Student Performance Predictor

An end-to-end Machine Learning project that predicts students’ academic performance based on socio-economic and educational factors. The project is deployed on AWS with a full CI/CD pipeline.

🚀 Tech Stack

Language: Python

ML Libraries: scikit-learn, pandas, numpy

Web Framework: Flask

Deployment: AWS Elastic Beanstalk / EC2 / S3 / CodePipeline

Version Control: Git & GitHub

⚙️ Project Workflow

Data Collection & Cleaning – processed the student dataset

EDA & Feature Engineering – visualized correlations and transformed categorical data

Model Building – trained multiple models (Logistic Regression, Random Forest, Gradient Boosting)

Model Evaluation – compared models using accuracy, F1-score, and ROC-AUC

Model Deployment – hosted the model as a Flask web app on AWS


☁️ Deployment

Configured AWS CodePipeline for CI/CD

Hosted Flask app on AWS Elastic Beanstalk

Connected to S3 bucket for model artifacts

📊 Results

Achieved ~85.50% accuracy on test data

Optimized model using GridSearchCV
